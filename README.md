# 銅銅 🎨 — 插畫師（插畫 / 水彩 / 數位）

**嗨，我是銅銅。** 我畢業於餐旅系，但從小就很愛畫畫。後來學了數位繪圖與水彩，慢慢累積了不少作品。插畫是我一直想努力的方向：我喜歡用圖畫表達想法，也很享受創作的過程。目標是把興趣變成穩定的工作，一邊做一邊學。

5. 完稿交付（JPG/PNG，必要時提供 PSD）
